# 끝말잇기 — AI 5단계 + 온라인 2인

## 데이터
- `data/끄글_단어 목록_20260819124154.txt`: 전체 단어 목록
- `data/끄글_공격 단어_20260819124810.txt`: 공격 단어 및 깊이

서버가 이 두 파일을 시작할 때 직접 읽습니다. 별도의 일반 한국어 사전으로 대체하지 않습니다.

## Windows 실행
1. Node.js LTS를 설치합니다.
2. 이 폴더에서 명령 프롬프트/PowerShell을 엽니다.
3. `npm install`
4. `npm start`
5. 브라우저에서 `http://localhost:3000` 접속

온라인 2인 테스트는 같은 PC에서는 `localhost:3000`으로, 같은 Wi-Fi의 다른 기기에서는 PC의 사설 IP 주소와 `:3000`을 사용하면 됩니다. 인터넷을 통한 외부 접속은 서버를 인터넷에 공개할 수 있는 호스팅/VPS가 추가로 필요합니다.

## 기능
- 랜덤 시작 단어
- 시작 단어에서 공격 단어 제외
- 5단계 AI
- 공격 단어 깊이 표시
- AI 승률/승패/평균 턴 localStorage 저장
- 온라인 2인 방 코드
- Socket.IO 실시간 턴 동기화
- 서버 측 단어/중복/끝 글자/턴 검증
- 반응형 모바일/PC UI
